# FocalMassLedger boundary and comparison

Action → native roster member pins a published statement → leader and each validator independently fetch the full bytes, verify SHA-256 and interpret compatibility with all three fixed alternatives → exact whole-report agreement → discounted simple-support contribution → exact intersection convolution over all active contributions → root-bound belief/plausibility reads. Only the contributor can withdraw its own contribution. The ledger recomputes from retained contributions, including after total conflict.

The creator fixes the three abstract alternatives, roster and integer reliabilities before statements arrive. Reliabilities are declared modeling assumptions. A participant endorses the published text with its native account, and the SHA-256 binds the document bytes. Publisher identity, independence, and any events described in the text remain outside the model.

Any UNKNOWN in the three-label vector yields a vacuous full-frame contribution, with no exclusions inferred from partially understood text. Known all-EXCLUDES yields an empty focal set, retaining self-conflict. Full-frame mass is ignorance, not uniform probability over alternatives.

For focal mask F and declared reliability q/1000, m(F)=q/1000 and m(frame)+=(1000-q)/1000. Combine by intersection: m(A)=sum over B∩C=A of m1(B)m2(C). Preserve m(empty) as conflict. No normalization by 1-conflict exists, so total conflict never divides by zero or issues a falsely certain answer. Belief and plausibility exclude empty-set mass; both use the raw common denominator. Withdrawals recompute rather than divide an accumulated mass function.

This standard unnormalized conjunctive combination is attributed to [Philippe Smets](https://arxiv.org/abs/1303.5430), not invented here. Distinct-source assumptions matter: correlated opinions, copied claims and Sybil-controlled roster entries can overcount support. Native account binding is not proof of source independence. Alternatives are abstract mutually exclusive declared cases, not proof that a real-world hypothesis list is exhaustive.

## Compared with existing mechanisms

- EvidenceFusionOracle refreshes YES/NO external-reality snapshots. This ledger combines retractable discounted set masses and preserves conflict; it makes no truth verdict.
- SealedBeliefScoreboard seals scalar probabilities, resolves an external outcome and computes Brier scores. There is no commitment/reveal, outcome resolution, score or payment here.
- LikelihoodPathLatch has a sequential first-boundary stopping rule. Here conjunction is order-independent and withdrawal can recover from total conflict; there is no likelihood boundary or stopping test.
- SemanticHypothesisLab learns a Boolean function family from one teacher's labeled examples. Here there is no feature function family, hypothesis search, experiment selection or teacher authority; the maintained object is an exact eight-cell mass function.
- ParaphraseDistanceCodec generates separated text carriers and decodes edits. This ledger neither generates paraphrases nor encodes a symbol channel.
- Owner-controlled graph variants update object/edge heads through proposals. Here there are no graph edges, parent versions, proposals, certificates, consumption or owner finalization.

Generic native encrypted-CLI transport and Windows direct-test cleanup are reused under MIT attribution. Global novelty and steward acceptance are not guaranteed. One representative mechanism is implemented.
